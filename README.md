# awesomeUI

Shared widget library for the GoldenNugget family of projects, split into
branches:

- **`python`** — the PySide6 package GoldenNugget imports as `awesomeui`
  (`Sidebar`, `IOSSwitch`, `phone_frame`, `MultiComboBox`,
  `resizable_image_label`). Added to GoldenNugget as a git submodule.
- **`swift`** — SwiftUI variants (`ReusableWidgets.swift`).
- **`main`** — this README only.
