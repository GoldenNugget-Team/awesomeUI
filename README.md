# awesomeUI (Python)

PySide6 control library used by GoldenNugget: `Sidebar`, `SidebarTheme`,
`IOSSwitch`, `phone_frame`, `MultiComboBox`, `resizable_image_label`.
License: see `LICENSE`.

This branch is the importable Python package; `main` holds the project
README, and `swift` holds SwiftUI variants.
